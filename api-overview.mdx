## What's coming

The API will include:

- **Agent management** — Create, update, and configure agents programmatically
- **Call history** — Query call records, transcripts, and recordings
- **Phone numbers** — Provision and manage numbers via API
- **Webhooks** — Subscribe to events like call started, call ended, action triggered
- **Knowledge base** — Upload and manage documents programmatically
