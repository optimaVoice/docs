Give your agent knowledge. Upload PDFs, FAQs, and documents. Your agent searches them during calls and answers from your content.

---

## What you can add

- **PDFs** — Manuals, guides, policies
- **Text files** — FAQs, procedures
- **Word documents** — Standard content
- **Website URLs** — Import from any public page
- **Text snippets** — Write quick answers directly

**Max per organization:** 50 MB

---

## Adding content

### Upload files

1. Click **Add Knowledge**
2. Select **Upload Files**
3. Choose PDFs, text, or Word docs
4. Wait for processing (30-60 seconds)

<Note>
Files must be under 10 MB. Processing takes up to a minute.
</Tip>

### Add a website

1. Click **Add Knowledge**
2. Select **Add URL**
3. Paste the website address
4. Click **Import**

We'll crawl the page and add it to your knowledge base.

### Create a text snippet

1. Click **Add Knowledge**
2. Select **Text Snippet**
3. Enter a title (the question)
4. Enter the answer
5. Click **Save**

Example:
- **Title:** What is your return policy?
- **Answer:** We accept returns within 30 days with original receipt. Items must be unused.

---

## How it works

When a caller asks a question:

1. Agent searches your knowledge base
2. Finds relevant content
3. Quotes directly from your documents

Example:
- Caller: "What's your return policy?"
- Agent: "According to our policy document, we accept returns within 30 days with the original receipt."

---

## Organizing knowledge

### Use folders

Create folders to keep things organized:

1. Click **New Folder**
2. Name it (e.g., "Policies," "Product Info")
3. Drag items into folders

### Set priority

Drag items up or down. Items at the top are searched first.

---

## Connecting to agents

Knowledge is shared across your organization by default. To limit specific agents:

1. Go to agent settings
2. Find **Knowledge Base**
3. Select which folders this agent can access

<Note>
This lets sales agents see product docs while support agents see troubleshooting guides.
</Tip>

---

## Best practices

✅ **DO:**
- Use clear headings in documents
- Write in plain language
- Update content when info changes
- Use Q&A format for FAQs

❌ **DON'T:**
- Upload scanned images (use text instead)
- Include outdated pricing or policies
- Upload confidential data

## Troubleshooting

<AccordionGroup>
  <Accordion title="Agent isn't using my knowledge">
    Check: Is processing complete (green checkmark)? Did you mention the knowledge base in Voice Instructions? Try: "Use the knowledge base to answer detailed questions."
  </Accordion>
  <Accordion title="Agent gives wrong answers">
    Review and update your content. Make sure it's clear and current.
  </Accordion>
  <Accordion title="Upload fails">
    Check: File under 10 MB? Supported format (PDF, TXT, DOCX)? Under 50 MB total?
  </Accordion>
</AccordionGroup>
